# LAIChat

Локальный AI-чат с веб-интерфейсом и базами знаний в Markdown.
Работает полностью на вашем компьютере — ни один запрос не уходит в сеть.

Разработано командой https://geriot.ru/

## Возможности

- 🌐 **Веб-интерфейс** — открывается в браузере, ответы рендерятся как Markdown (код, списки, таблицы, цитаты)
- 📦 **Готовый установщик** — `LAIChat-Setup-1.0.0.exe`, ставится двойным кликом: Node.js, llama.cpp, ярлыки и деинсталлятор
- 🗂 **Базы знаний** — `.md` файлы из папки `bases/`, редактируются прямо в UI
- 🔎 **RAG на BM25** — в контекст подставляются релевантные фрагменты базы, а не вся база целиком
- ⚡ **Параллельный анализ** — модель опрашивает все базы, в чате видно какой раздел выбран и что предложили остальные
- 📄 **Импорт документов** — DOCX конвертируется в Markdown и нарезается на чанки
- 🤖 **Провайдеры** — llama.cpp, Ollama, Gemini, любой OpenAI-совместимый API
- ⚙️ **Настройки из UI** — контекст, потоки CPU, температура, top-p, max tokens, таймаут, отключение анализа
- ⏱ **Замеры времени** — видно, сколько занял анализ баз и генерация ответа
- 🛡 **Разбор ошибок** — при переполнении контекста или таймауте приложение предлагает начать новый чат
- 🔒 **Полностью офлайн** — работа с локальной моделью не требует интернета

## Установка (Windows)

Скачайте `LAIChat-Setup-1.0.0.exe` из раздела [Releases](https://github.com/SwargHUB/LAIChat/releases)
и запустите. Мастер предложит:

1. выбрать папку установки (по умолчанию `%LOCALAPPDATA%\Programs\LAIChat`)
2. выбрать компоненты: приложение, llama.cpp, примеры баз знаний
3. указать файл модели `.gguf` — или добавить её позже
4. создать ярлыки на рабочем столе и в меню «Пуск»

Установщик сам размещает портативный Node.js — системные зависимости не нужны.
Модель (1–2 ГБ) в установщик не входит: её нужно скачать отдельно и положить
в папку `models` рядом с программой.

Удаление — стандартное: «Пуск» → LAIChat → «Удалить LAIChat». Модель и базы
знаний при этом сохраняются.

## Запуск из исходников

```bash
npm install
npm run dev        # http://127.0.0.1:3000
```

Требуется Node.js 18+.

```bash
npm run build         # сборка фронтенда в dist/
npm run build:server  # сборка сервера в server.js
npm run start:prod    # продакшн-режим: раздаёт dist/
```

### Модель

Положите `.gguf` в папку `models/`. Сервер сам найдёт её, поднимет
`llama-server` из `bin/` и подключится к нему. Имя модели можно поменять
в настройках; при первом запуске подхватывается первая найденная.

### llama.cpp

Бинарь `llama-server` должен лежать в `bin/`:

```bash
# скачать с https://github.com/ggml-org/llama.cpp/releases/latest
# архив bin-win-cpu-x64 для Windows, распаковать в ./bin/
```

## Базы знаний

Каждая база — обычный Markdown-файл с YAML-фронтматтером:

```markdown
---
name: Go
description: Язык Go: горутины, каналы, модули, интерфейсы, тестирование
---

# Go (Golang)

## Горутины и каналы
...
```

- `name` — имя темы для классификатора (если не задать, возьмётся имя файла)
- `description` — ключевые слова, по которым модель выбирает базу
- остальное — содержимое, из которого BM25 выбирает релевантные фрагменты

Файлы можно создавать, редактировать и удалять прямо в UI (вкладка «Базы»),
либо положить `.md` в папку `bases/` и нажать «Перечитать базы».

### Как выбирается база

1. **Параллельный анализ** — модель получает все базы и отвечает по одной JSON-схеме:
   либо краткий ответ, либо `N/A: <почему не по теме>`
2. **Быстрый режим** (анализ выключен в настройках) — база выбирается по словам,
   без дополнительного вызова модели
3. **Синтез** — выбранная база подставляется в контекст; если она большая,
   BM25 отбирает 2–3 релевантных фрагмента вместо всей базы

## Настройки

Меняются в UI (вкладка «Настройки») и сохраняются в `settings.json`:

```json
{
  "context_size": 16384,
  "threads": 8,
  "max_tokens": 1024,
  "temperature": 0.7,
  "top_p": 0.9,
  "backend_provider": "llama_cpp",
  "llama_server_url": "http://127.0.0.1:8080",
  "openai_base_url": "https://api.openai.com/v1",
  "openai_api_key": "",
  "model_name": "model",
  "request_timeout": 300,
  "parallel_analysis": true
}
```

> `context_size` и `threads` применяются только после перезапуска
> llama-server — в приложении это делает кнопка «Перезапустить сервер».

### Переменные окружения

| Переменная | Что | По умолчанию |
|---|---|---|
| `PORT` | порт веб-сервера | `3000` |
| `LAICHAT_OPEN_BROWSER` | `0` — не открывать браузер при старте | `1` |
| `GEMINI_API_KEY` | ключ Gemini (переключает провайдера по умолчанию) | — |
| `OPENAI_API_KEY` | ключ OpenAI-совместимого API | — |
| `OPENAI_BASE_URL` | адрес OpenAI-совместимого API | `https://api.openai.com/v1` |

## HTTP API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/state` | конфиг, статус сервера, список баз и моделей |
| `POST` | `/api/config` | изменить настройки генерации |
| `POST` | `/api/chat` | `{message}` → `{response, source, analyses[], timings}` |
| `POST` | `/api/clear` | очистить историю |
| `POST` | `/api/restart` | перезапустить llama-server и перечитать базы |
| `POST` | `/api/reload` | перечитать папку `bases/` |
| `GET` | `/api/bases` | список баз |
| `GET` | `/api/bases/{name}` | содержимое базы |
| `PUT` | `/api/bases/{name}` | сохранить базу |
| `POST` | `/api/bases` | создать базу |
| `DELETE` | `/api/bases/{name}` | удалить базу |
| `GET` | `/api/models` | список `.gguf` из папки `models/` |
| `POST` | `/api/convert-doc` | конвертация DOCX в Markdown и чанки |
| `POST` | `/api/import-chunks` | импорт чанков в базы знаний |
| `POST` | `/api/search` | BM25-поиск по базам |
| `POST` | `/api/test-connection` | проверка связи с провайдером |

Пример:

```bash
curl -X POST localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Как создать горутину в Go?"}'
```

```json
{
  "response": "Горутина создаётся ключевым словом go...",
  "source": "Go",
  "analyses": [
    {"name": "Bash", "answer": "N/A: вопрос не про командную строку", "chosen": false},
    {"name": "Go",   "answer": "Горутины запускаются через go func(){}", "chosen": true}
  ],
  "timings": {"analysis_mode": "parallel", "analysis_ms": 14062, "answer_ms": 31410, "total_ms": 45474}
}
```

## Сборка установщика

```powershell
winget install JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Скрипт сам соберёт фронтенд и сервер, поставит прод-зависимости, скачает
портативный Node.js и скомпилирует `.exe` в `installer/release/`.

| Параметр | Значение |
|---|---|
| `-Version` | версия в имени файла, по умолчанию `1.0.0` |
| `-NodeVersion` | версия Node.js, по умолчанию `v24.13.0` |
| `-SkipNodeDownload` | использовать системный Node.js вместо портативного |

Готовый установщик — `installer/release/LAIChat-Setup-1.0.0.exe` (34 МБ).

## Безопасность

Сервер слушает только `127.0.0.1` и не имеет аутентификации. Запросы из
локальной сети блокируются по умолчанию. Не выставляйте порт в интернет.

## Решение проблем

**«llama-server не найден»** — положите бинарь в `bin/`, на Linux/macOS `chmod +x`

**«модель не найдена»** — файл `.gguf` должен лежать в `models/`

**«Контекст модели переполнен»** — начните новый чат (приложение предложит
кнопку), увеличьте `context_size` или уменьшите `max_tokens`

**Долгий ответ** — при большом числе баз параллельный анализ добавляет
один вызов модели; отключите его в настройках (параметры запроса)

**Порт занят** — `PORT=3001 npm run dev`
